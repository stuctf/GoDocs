# Go 1.24 Release Changes (February 2025)

> Within Claude's training data (cutoff June 2026). Well covered, but some details are commonly missed.
> Source: https://go.dev/doc/go1.24

## Language Changes

### Generic type aliases

Type aliases can now have type parameters:
```go
type set[P comparable] = map[P]bool
```
Disable with `GOEXPERIMENT=noaliastypeparams` (removed in Go 1.25).

## Tools

### Go command

- **`tool` directives in go.mod**: Track executable dependencies directly. Replaces the `tools.go` blank-import workaround. `go get -tool` adds a tool directive. `tool` meta-pattern refers to all tools in the module (`go get tool`, `go install tool`).
- **`go run` / `go tool` caching**: Executables now cached in the build cache.
- **`go build -json` / `go install -json`**: Structured JSON output for build results and failures.
- **`go test -json`**: Now includes build output in JSON with new `Action` types. GODEBUG `gotestjsonbuildtext=1` reverts to text.
- **`GOAUTH` env var**: Flexible authentication for private module fetches.
- **`go build` VCS version**: Main module version auto-set from VCS tag/commit. `+dirty` suffix for uncommitted changes. `-buildvcs=false` to omit.
- **`GOCACHEPROG`**: External cache implementation via child process JSON protocol. Graduated from GOEXPERIMENT.
- **GODEBUG `toolchaintrace=1`**: Trace toolchain selection.

### Cgo

- **`#cgo noescape cFunctionName`**: Tells compiler memory passed to C function doesn't escape.
- **`#cgo nocallback cFunctionName`**: Tells compiler C function doesn't call back to Go.
- Better detection of incompatible C function declarations across files.

### Vet

- **`tests` analyzer**: Reports malformed test/fuzz/benchmark/example declarations (bad names, wrong signatures, examples for nonexistent identifiers). Run by `go test`.
- **`printf` analyzer**: Flags `fmt.Printf(s)` with non-constant format string and no args. Only when go version >= 1.24.
- **`buildtag` analyzer**: Flags invalid Go major version constraints like `//go:build go1.23.1` (point releases not valid).
- **`copylock` analyzer**: Flags `sync.Locker` in 3-clause for loop variables (Go 1.22 per-iteration copy is unsafe for locks).

### Objdump

Supports loong64, riscv64, s390x.

## Runtime

- **Swiss Tables map**: New builtin `map` implementation. Disable with `GOEXPERIMENT=noswissmap`.
- **Faster small object allocation**.
- **New runtime-internal mutex**: Disable with `GOEXPERIMENT=nospinbitmutex`.
- **2-3% average CPU overhead reduction** from above combined.

## Compiler

- Receiver types that are cgo-generated (even via alias) are now always rejected.

## Linker

- **GNU build ID** (`NT_GNU_BUILD_ID`) on ELF and **UUID** (`LC_UUID`) on macOS generated by default, derived from Go build ID. Disable with `-B none`, override with `-B 0xNNNN`.

## New Packages

### `os.Root` — directory-limited filesystem access

`os.OpenRoot` opens a directory, returns `os.Root`. Methods mirror `os` package but cannot escape the directory (including via symlinks). Methods: `Open`, `Create`, `Mkdir`, `Stat`, etc.

### `testing.B.Loop` — better benchmarking

```go
for b.Loop() { ... }  // replaces for range b.N { ... }
```
- Benchmark function executes exactly once per `-count`
- Function call params and results kept alive (prevents over-optimization)

### `runtime.AddCleanup` — better finalizers

More flexible, efficient, and less error-prone than `SetFinalizer`:
- Multiple cleanups per object
- Works with interior pointers
- No cycle-caused leaks
- No delayed freeing

### `weak` package — weak pointers

For memory-efficient structures: weak maps, canonicalization maps, caches. Used with `runtime.AddCleanup` and `maphash.Comparable`.

### `crypto/mlkem` — post-quantum key exchange

ML-KEM-768 and ML-KEM-1024 (formerly Kyber, FIPS 203).

### `crypto/hkdf`, `crypto/pbkdf2`, `crypto/sha3`

Promoted from `golang.org/x/crypto/...` to stdlib.

### FIPS 140-3 compliance

- `GOFIPS140` env var selects Go Cryptographic Module version.
- `fips140` GODEBUG enables FIPS 140-3 mode at runtime.
- v1.0.0 included, under CMVP lab testing.

### `testing/synctest` (experimental)

Requires `GOEXPERIMENT=synctest`. `synctest.Run` starts goroutines in isolated "bubble" with fake clock. `synctest.Wait` waits for all goroutines to block. Graduates to GA in Go 1.25.

## Standard Library Highlights

### `encoding/json`

- **`omitzero` struct tag option**: Omits field if zero value (or if `IsZero() bool` returns true). Cleaner than `omitempty` for `time.Time` etc. Both can coexist — field omitted if either condition met.
- `UnmarshalTypeError.Field` now includes embedded structs.

### `crypto/rand`

- **`Read` guaranteed not to fail**: Always returns `nil` error. Crashes if underlying read fails. Platform APIs documented to always succeed.
- **Linux 6.11+**: Uses `getrandom` via vDSO (several times faster for small reads).
- **`Text` function**: Generate cryptographically secure random text strings.

### `crypto/cipher`

- **`NewGCMWithRandomNonce`**: Returns `AEAD` that auto-generates random nonce during Seal, prepends to ciphertext.
- `NewCTR` with `crypto/aes` is several times faster on amd64/arm64.
- `NewOFB`, `NewCFBEncrypter`, `NewCFBDecrypter` **deprecated** (not authenticated).

### `crypto/ecdsa`

- `PrivateKey.Sign` with `nil` random source now produces **deterministic signatures** per RFC 6979.

### `crypto/rsa`

- **1024-bit minimum**: `GenerateKey` errors for <1024-bit keys. All Sign/Verify/Encrypt/Decrypt error for <1024-bit. GODEBUG `rsa1024min=0` to revert (tests only).
- `Precompute` before `Validate` is now safe and more efficient.
- Uses Carmichael's totient instead of Euler's totient for private exponent.
- `SignPKCS1v15` / `VerifyPKCS1v15` support SHA-512/224, SHA-512/256, SHA-3.
- 2x faster on wasm.

### `crypto/tls`

- **Encrypted Client Hello (ECH)** server support via `Config.EncryptedClientHelloKeys`.
- **X25519MLKEM768** enabled by default. Disable with `tlsmlkem=0`.
- `X25519Kyber768Draft00` removed.
- Key exchange ordering handled by `crypto/tls`; `CurvePreferences` order ignored (only used to select which exchanges to enable).
- `ClientHelloInfo.Extensions` field for TLS client fingerprinting.

### `crypto/x509`

- `x509sha1` GODEBUG removed. SHA-1 signatures no longer supported in `Verify`.
- Default policy field changed from `PolicyIdentifiers` to `Policies`. GODEBUG `x509usepolicies=0` to revert.
- `CreateCertificate` auto-generates serial number if `nil`.
- `Verify` supports policy validation (RFC 5280/9618) via `VerifyOptions.CertificatePolicies`.
- `MarshalPKCS8PrivateKey` returns error for invalid RSA keys.
- `ParsePKCS1PrivateKey` / `ParsePKCS8PrivateKey` validate CRT values. GODEBUG `x509rsacrt=0` to revert.

### `encoding`

- **`TextAppender` and `BinaryAppender` interfaces**: Append textual/binary representation to existing slice instead of allocating. Implemented by many stdlib types.

### `hash/maphash`

- **`Comparable` and `WriteComparable`**: Hash any comparable value. Hash anything usable as a Go map key.

### `net`

- `ListenConfig` uses **MPTCP by default** on Linux.

### `net/http`

- **`Server.Protocols` / `Transport.Protocols`**: Configure which HTTP protocols to use.
- **Unencrypted HTTP/2** support ("HTTP/2 with Prior Knowledge", RFC 9113 §3.3). Server accepts both HTTP/1 and h2c on same port. Transport uses h2c for `http://` URLs when configured.
- `Transport` 1xx response limit changed from count-based (5) to size-based (`MaxResponseHeaderBytes`). No limit when `Got1xxResponse` trace hook is set.
- `Transport` and `Server` HTTP2 field for HTTP/2 settings.

### `bytes` and `strings`

Iterator functions: `Lines`, `SplitSeq`, `SplitAfterSeq`, `FieldsSeq`, `FieldsFuncSeq`.

### `text/template`

Range-over-func and range-over-int support.

### `sync.Map`

New implementation (sync hash trie map). Better performance, especially for modifications. Disjoint key modifications don't contend on large maps. No ramp-up time for low-contention loads. Disable with `GOEXPERIMENT=nosynchashtriemap`.

### `testing`

- **`T.Context` / `B.Context`**: Returns context canceled after test completes, before cleanup runs.
- **`T.Chdir` / `B.Chdir`**: Change working directory for duration of test/benchmark.

### `go/types`

All sequence types (Len/At pairs) now also have iterator methods: `Interface.EmbeddedTypes`, `Interface.ExplicitMethods`, `Interface.Methods`, `MethodSet.Methods`, `Named.Methods`, `Scope.Children`, `Struct.Fields`, `Tuple.Variables`, `TypeList.Types`, `TypeParamList.TypeParams`, `Union.Terms`.

### `log/slog`

- `DiscardHandler`: Never enabled, discards all output.

### `runtime`

- `GOROOT` function deprecated. Use `go env GOROOT` instead.

### `debug/elf`

- `File.DynamicVersions`, `File.DynamicVersionNeeds` methods.
- `Symbol.HasVersion`, `Symbol.VersionIndex` fields.

### WebAssembly

- **`go:wasmexport`** directive for exporting functions to Wasm host.
- **`-buildmode=c-shared`** for wasip1 (reactor/library mode).
- More types allowed in `go:wasmimport`/`go:wasmexport`: `bool`, `string`, `uintptr`, certain pointer types.
- Support files moved from `misc/wasm` to `lib/wasm`.
- Reduced initial memory size.

## Ports

- **Linux**: Requires kernel 3.2+.
- **Darwin**: Last release for macOS 11 Big Sur. Go 1.25 requires macOS 12+.
- **Windows/arm (32-bit)**: Marked broken.
